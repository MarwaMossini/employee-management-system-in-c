# Employee Management System in C

A console application developed by a team of three students for the GE-CSDA1001 course, completed on April 8, 2025.

## Features
- Add and delete employee records.
- Search employees by name or ID.
- Update salaries based on extra working hours.
- Assign departments based on qualifications.
- Update employee ranks based on work experience.
- List employees by department and display the total employee count.

## Technologies
C programming language and the CS50 library. Developed in the CS50 coding environment.

## How to Run
In the CS50 terminal:
```bash
make employee_management
./employee_management
```

## Notes
Records are stored in memory and reset when the program restarts. The current version performs one menu operation per run.
